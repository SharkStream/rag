# 什么是公司财报？(Financial Statements)

**公司财报**（Financial Statements，全称**公司财务报告**）是企业定期向股东、投资者、银行及政府监管机构披露的“财务成绩单”。它通过一系列规范化的数字，全面反映了公司在特定时期内的**经营成果**、**财务状况**以及**现金流动情况**。

对于投资者而言，财报是评估一家公司是否值得投资、是否存在破产风险的最核心依据。

---

## 一、 核心组成：经典的“三张表”

一份标准的非金融企业财报，最核心的是以下三张财务报表，它们从不同维度拆解了公司的资金秘密：

| 报表名称 | 核心关注点 | 俗称与通俗理解 |
| :--- | :--- | :--- |
| **资产负债表**<br>(Balance Sheet) | 公司在**某一特定日期**的资产、负债及股东权益状况。 | **底子**：看公司有多少家底，欠了多少钱，净资产是多少。 |
| **利润表 / 损益表**<br>(Income Statement) | 公司在**一段时间内**赚了多少钱，花了多少钱。 | **面子**：看公司营业收入是多少，净利润高不高，赚钱能力如何。 |
| **现金流量表**<br>(Cash Flow Statement) | 公司在**一段时间内**现金流入和流出的真实情况。 | **日子**：看公司账上有没有真金白银，防范“有利润却没现金”的破产风险。 |

### 💡 经典公式：
*   **资产负债表基本等式**：`资产 = 负债 + 所有者权益（股东权益）`
*   **利润表基本等式**：`收入 - 费用 = 利润`

---

## 二、 财报的披露周期

上市公司通常按照法律规定，在固定的时间节点发布报告：

*   **季报（Quarterly Report）**：每隔 3 个月发布一次（Q1、Q2、Q3、Q4），时效性强，能快速反映公司近期的业务短期变动。
*   **半年报（Semi-Annual Report）**：年中（通常在 6-8 月）披露的上半年业绩总结。
*   **年报（Annual Report）**：**最重要、内容最全面**的报告，通常在次年 1-4 月底前披露，且必须经过独立的**会计师事务所审计**。

---

## 三、 读财报时，高手都在看什么？

看财报不仅仅是看“净利润”这一个数字，通常需要结合以下几个维度来判断公司的优劣：

1.  **增长能力**：营业收入和净利润是否同比（比去年同期）增长？增长率是否跑赢了同行业对手？
2.  **盈利质量**：毛利率高不高？如果一家公司营业收入很高，但毛利率极低，说明产品技术壁垒不高，缺乏核心竞争力。
3.  **资产安全性**：资产负债率是多少？如果负债过高（如超过 70%-80%），一旦遭遇市场寒冬或银行抽贷，公司极易面临资金链断裂。
4.  **真金白银**：经营活动产生的现金流量净额是否为正？只有收回“真现金”的利润，才是健康的、没有水分的利润。
