# Python 人工智能（AI）开发工程师招聘要求

## 一、 核心硬技能（技术底座）

*   **精通 Python 异步高并发与工程化**
    *   精通 Python 核心语法，具备深厚的面向对象及函数式编程功底。
    *   熟练掌握 `asyncio`、多进程/多线程并发编程，能够处理 AI 推理时的高并发、低延迟需求。
    *   熟练使用高性能 Web 异步框架（如 **FastAPI**）来构建 AI 模型的 API 接口。

*   **熟练掌握主流深度学习与 AI 框架**
    *   精通 **PyTorch**（行业绝对主流）或 TensorFlow，能熟练进行网络结构搭建、模型训练、微调（Fine-tuning）和推理。
    *   熟练使用科学计算与数据处理库：**NumPy**、**Pandas**、Scikit-learn。

*   **算力、基础设施与模型部署**
    *   熟练掌握 Linux 操作系统及 **Docker / Kubernetes (K8s)** 容器化部署。
    *   熟悉 GPU 算力调度，掌握 **CUDA** 原理、**TensorRT**、ONNX 等模型压缩、量化及加速推理技术。
    *   熟悉向量数据库（如 **Milvus**、Chroma、Pinecone），用于海量数据的检索与匹配。

## 二、 2026 核心核心：大模型与生成式 AI（GenAI）要求

目前几乎所有 AI 岗位都将大模型能力列为标准配置：

*   **LLM 与 RAG 开发经验**
    *   熟练掌握 **LangChain**、**LlamaIndex** 等大模型编排框架，具备 **RAG（检索增强生成）** 架构的落地经验。
    *   熟练对接国内外主流大模型 API（如 OpenAI、Anthropic、智谱 AI、DeepSeek 等），掌握高级 Prompt 提示词工程。

*   **智能体（Agent）架构设计**
    *   熟悉 Agent（智能体）概念，具备使用 **CrewAI**、**AutoGen** 或 LangGraph 开发多智能体协同、工具调用（Function Calling）、长期记忆和反思机制系统的经验。

*   **大模型微调（加分项）**
    *   了解大模型微调技术（如 **LoRA**、QLoRA、P-Tuning），有使用 Hugging Face `transformers` 库进行开源大模型（如 Llama 3、Qwen）本地私有化部署和微调经验。

## 三、 经典 AI 方向需求（视业务板块而定）

根据公司具体业务，通常会要求精通以下某一个垂直领域：

*   **方向 A：自然语言处理 (NLP)**
    *   熟悉 Transformer、BERT、RNN 等经典架构；具备文本分类、命名实体识别（NER）、情感分析、知识图谱构建经验。
*   **方向 B：计算机视觉 (CV)**
    *   熟悉 CNN、ViT（Vision Transformer）、YOLO、Segment Anything (SAM) 等架构；具备目标检测、图像分割、视频分析或 OCR（文字识别）项目经验。
*   **方向 C：多模态 (Multimodal)**
    *   熟悉 CLIP、Diffusion Models（扩散模型）等，具备图生文、文生图、音视频多模态理解与生成的实际落地经验。

## 四、 数学基础与工程素养（软实力）

*   **扎实的数学功底**：深刻理解线性代数、概率论与数理统计、最优化理论（如梯度下降），能够看懂并复现前沿 AI 论文（如 arXiv 最新论文）。
*   **良好的代码素养**：严格遵循 PEP8 规范，注重代码的稳定性和可测试性（pytest），具备编写高质量技术文档的习惯。
*   **敏锐的技术嗅觉**：AI 技术日新月异，必须具备极强的自我驱动力和快速学习新框架、新算法（如最新开源大模型）的能力。
